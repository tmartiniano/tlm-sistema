# Decisões aprovadas

## DEC-001 — EasyPanel

O EasyPanel será o painel oficial para instalação, configuração, publicação e administração dos serviços.

## DEC-002 — Banco local

O PostgreSQL ficará hospedado na própria VPS, sem serviços externos nesta fase.

## DEC-003 — Caso inicial

O Trilha do Sabor será o primeiro cliente e caso de validação.

## DEC-004 — Nome do sistema

O nome comercial do sistema ainda não foi definido.

## DEC-005 — Aplicação inicial

A primeira versão será uma aplicação única para reduzir a complexidade operacional.

## DEC-006 — Interface

A interface será desenvolvida em português do Brasil, com foco visível e navegação acessível.

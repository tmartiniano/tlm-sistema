# Procedimentos operacionais

## Infraestrutura

O EasyPanel deve ser utilizado para controlar os serviços instalados.

## Banco de dados

O PostgreSQL deverá possuir armazenamento persistente e não poderá publicar a porta 5432 na internet.

## Segredos

Senhas, tokens, chaves privadas e arquivos `.env` não devem ser versionados.

## Alterações

Toda alteração relevante deve ser registrada na documentação do projeto.
